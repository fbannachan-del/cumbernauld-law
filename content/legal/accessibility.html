Accessibility

Browser support

This website works in current versions of Chrome, Edge, Firefox and Safari, on both desktop and mobile devices.

Limitations

At the time of launching this website, there are no known limitations which may negatively affect the access and utilisation for any group of users.

Navigation

We have made all efforts to ensure this website can be accessed without the use of a mouse. This can be done by moving between page links by using the ‘Tab’ key on your keyboard. To tab through links in reverse, you would use ‘Tab+Shift’. Once you have selected the appropriate link, you would press the ‘Enter’ key to activate and follow the link.

Readability

To adjust the readability of this website, you can increase and decrease the size of the text on the Cumbernauld Law Practice website by using the tools that are built into your web browser.

Difficulty using this website

If you have any difficulty using this website, please phone us on 01236 731911.
